# Public Transport Timetable & Delay Tracker

## Overview
A scripting project that processes public transport timetable and arrival data, calculates delays, generates reports and charts, and supports delay alerts and automated execution.

## Modules
1. Data Ingestion
2. Delay Calculation & Processing
3. Reports & Charts
4. Alerts
5. Logging & Automation

## Project Structure
- `data/` — input and processed data
- `scripts/` — module scripts
- `reports/` — generated reports and charts
- `logs/` — execution logs
- `config/` — shared configuration
- `tests/` — test cases and sample data
- `docs/` — project and module documentation

## Status
Initial project structure created. Data contracts and module interfaces are pending team approval.
